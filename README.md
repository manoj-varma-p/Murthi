# Rai Praveen — Creative Portfolio

> **Graphic Designer, Video Editor & Motion Graphic Designer**  
> *"Motion, Applied Differently."*

An ultra-modern, high-performance portfolio website built with Next.js 14, Tailwind CSS, and Framer Motion, engineered to deliver an editorial magazine-cover aesthetic across all devices and screen sizes.

---

## ✨ Features & Highlights

- **Magazine-Style Responsive Hero**: Proportional viewport-scaling composition (`vh`) that seamlessly adapts across mobile, tablet, laptop, 1080p, 1440p QHD, and 4K displays.
- **Interactive Dual-Lane Video Showcase**: Continuous infinite-scrolling marquee featuring 9:16 vertical video cards with instant hover previews and full YouTube modal playback.
- **Mobile Smooth Scroll Stacking**: Card stack mechanics optimized for mobile touch devices.
- **Interactive Preloader**: Dynamic typographic entrance sequence with custom running animator.
- **WhatsApp Direct Connect**: 1-click direct chat integration for client inquiries.
- **Custom Tab Branding**: Circular avatar favicon and app icons.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

---

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run local dev server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the site.

3. **Production build:**
   ```bash
   npm run build
   ```
